Como o score é calculado

Cada achado vale peso do dado × fator da saída. Pesos: localização e senha 10, saúde e token 9, CPF 8, contato 5, dispositivo 4. Fatores: envio a terceiros e resposta da API 1,0; arquivo 0,8; log 0,7; exceção 0,6; console e URL 0,5; dado fixo 0,4; risco latente (record sem ToString) 0,03.

Risco Cidadão = 100 × (1 − e−soma/15), com níveis: Baixo (< 25), Moderado (25–49), Alto (50–74), Crítico (≥ 75). Achados de severidade ERROR no código da API bloqueiam o pipeline.
