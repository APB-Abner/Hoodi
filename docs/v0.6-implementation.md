# v0.6 preparation — implementation boundaries

Runtime version: `0.6.0-draft`. This is an incremental implementation, not the completed H3 release. The full v0.5.3 contract and previous baselines remain unchanged; the partial logout contract is [here](../contracts/v0.6/logout.openapi.yaml).

## Logout

`POST /v1/auth/sair`, authenticated with the current JWT, accepts only `{ "instalacaoId": "..." }`. User and session come from validated `sub` and `sid`. One SQLite transaction revokes that session, clears its refresh replay payloads and deactivates the authenticated account's push for the supplied installation. Other sessions and installations remain valid. Missing push is allowed. The existing login does not bind an installation to a session; the client must send the identifier it used for push registration.

The client waits for 204 before clearing local credentials. A retry with the revoked JWT receives 401; that response alone does not establish that push was disabled. Invalid bodies return 400 and perform no logout. Native app integration remains to be tested.

## Snapshot scaffold

`SnapshotImportService` checks the exact CSV byte SHA-256, JSON syntax, duplicate cell/band keys, all five bands for every expected cell, status/count/level consistency and H3 through a required validator abstraction. `sem_dado` retains a null level. Expected coverage must come from the producer adapter's independently established perimeter set, not from the rows being imported.

`SnapshotPublicationStore` persists the complete package and switches a singleton current-version pointer in one transaction. Reimporting identical bytes is idempotent and does not reactivate an older version. Different bytes under an existing version are rejected. A failure after SQL writes rolls back both artifact and pointer. The additive `SnapshotPublicationSkeleton` migration creates only publication/head tables.

These are internal integration models, not frozen CSV/manifest DTOs. No producer decoder, real H3 validator, import endpoint, DI registration, cell query index or public snapshot route is enabled. Tests inject synthetic decoders and H3 whitelists; they prove orchestration and SQLite publication, not producer compatibility or real H3 validation. Raw package storage is the foundation for publication, not a completed risk lookup module.

Before enabling import, obtain the real CSV, SHA file, manifest and fixture. Implement the actual format adapter, enforce encoding/delimiters/columns, validate cuts and level calculations, period, bands, timezone, formula, warning, fixture correspondence and exact coverage. Select and approve the H3 dependency, validate actual H3 indexes and resolution, then finish public v0.6 DTOs and serving routes. Do not invent cuts, center or perimeter selection. See [the authoritative decisions](risk-snapshot-v1-v0.6.md).
